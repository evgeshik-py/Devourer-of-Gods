# DEVOURER OF GODS

**2D Boss Fight · JavaScript · HTML5 Canvas**

Браузерная игра с боями против боссов. Проект написан на JavaScript без использования игровых движков. Основная задача — реализация боевой системы, поведения боссов, атак и визуальных эффектов.

## О проекте

Devourer of Gods — экспериментальный игровой проект, в котором реализованы сражения с боссами в реальном времени. В разработке используются Canvas API для отрисовки игрового мира и Web Audio API для звукового сопровождения.

## Реализовано

- Боевая система и несколько видов оружия.
- Выбор сложности.
- Перемещение и управление полётом.
- Ускорение игрока.
- Способность Stellar Nova.
- Система атак и поведения босса.
- Частицы и визуальные эффекты.
- Звуковое сопровождение.
- Пауза и перезапуск игры.

## Управление

| Клавиша | Действие |
|:---:|---|
| WASD | Перемещение |
| Shift | Ускорение |
| ЛКМ | Атака |
| ПКМ | Stellar Nova |
| 1–4 | Смена оружия |
| Esc | Пауза |
| M | Звук |
